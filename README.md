# Decodable Internship Task 02 - Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the provided dataset using Python. The objective is to clean the data, identify patterns, analyze trends, and generate meaningful business insights through statistical analysis and visualizations.

## Objectives
- Understand the dataset structure
- Perform data cleaning and preprocessing
- Handle missing values
- Analyze key metrics and trends
- Create visualizations for better understanding
- Extract actionable insights

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## EDA Process
### 1. Data Understanding
- Dataset shape
- Data types
- Summary statistics

### 2. Data Cleaning
- Missing value treatment
- Duplicate removal
- Data validation

### 3. Univariate Analysis
- Distribution plots
- Count plots
- Summary statistics

### 4. Bivariate Analysis
- Correlation analysis
- Relationship between variables
- Comparative visualizations

### 5. Insights & Findings
- Key trends identified
- Business observations
- Recommendations

## Visualizations
The project includes:
- Histograms
- Box Plots
- Bar Charts
- Count Plots
- Correlation Heatmap
- Scatter Plots
